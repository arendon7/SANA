SANA · DATA ROOM · V176

External verification references

V176 permite representar únicamente dos estados claim-específicos: una referencia de resultado o una declaración explícita de no verificado en la fuente. No existe un estado `VERIFIED` y ninguna referencia valida la verdad del claim, al proveedor, el resultado o una certificación.

EXTERNAL_VERIFICATION_REFERENCE_ONLY ≠ VERIFIED RESULT · EXPLICITLY_NOT_VERIFIED_AT_SOURCE ≠ NEGATIVE PROJECT CONCLUSION · PROVIDER REF ≠ VERIFIED IDENTITY / QUALIFICATION / ACCREDITATION · NO VERIFIED STATE · COUNTS ONLY ≠ SCORE · READ ONLY.
