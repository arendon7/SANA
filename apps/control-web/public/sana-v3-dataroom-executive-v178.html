Evidence request & response handoff

Traza solicitudes y respuestas documentales claim-específicas. Una respuesta referenciada no significa evidencia aceptada, completa, suficiente ni finding resuelto.

REQUEST + RESPONSE ≠ EVIDENCE ACCEPTED · RESPONSE ≠ REQUEST COMPLETE ≠ SUFFICIENT EVIDENCE ≠ FINDING RESOLVED · DECLARED DUE DATE ≠ DEADLINE ENFORCEMENT · ADDITIONAL EVIDENCE REQUIRED AT REVIEW ≠ AUTO REQUEST CREATION · COUNTS ONLY ≠ SCORE · READ ONLY.
