Governance reference identifier resolution

V183 determina únicamente si los IDs declarados existen exactamente en los contratos Review Governance, Disposition y Round. Resolved ≠ verified ≠ valid ≠ authorized.

IDENTIFIER RESOLVED ≠ REFERENCE VERIFIED ≠ CASE VALID · DISPOSITION REF RESOLVED ≠ VALID DISPOSITION · ROUND ID RESOLVED ≠ REVIEW COMPLETED · ALL IDENTIFIERS RESOLVED ≠ AUTHORIZATION / COMPLIANCE / LEGAL EFFECT / DD APPROVAL / FINANCING.
