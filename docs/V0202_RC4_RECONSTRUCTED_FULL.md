## Security fix discovered during rc4

The reconstructed migration 0016 contained malformed dynamic SQL for tenant RLS policy creation. rc4 corrects the expression to the same valid tenant-setting form used by the hardened later migrations and extends the v0.16R guardrail to reject malformed quoting.
